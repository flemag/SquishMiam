# Jardin XP — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gamification : XP gagnés par actions, niveaux, jardin de plantes qui pousse sur la page Profil.

**Architecture:** Logique pure testée (`jardin.ts`) → migration additive (`xp` sur User) → helper `ajouterXp` → intégration dans les routes existantes → UI sur la page Profil (niveau, barre, jardin animé).

**Tech Stack:** Next.js 15 (App Router), Prisma, Vitest, Tailwind, CSS animations. Zéro nouvelle dépendance.

**Spec:** `docs/superpowers/specs/2026-11-24-jardin-xp-design.md`

## Global Constraints

- UI française, tutoiement.
- Mobile 360 px sans débordement ; cibles tactiles ≥ 44 px (`min-h-11`).
- Animations transform/opacity uniquement + `prefers-reduced-motion`.
- Aucune nouvelle dépendance npm ; migration additive uniquement.
- `npm test` et `npm run build` verts avant chaque commit.
- Git hors PATH : `"C:\Program Files\Git\cmd\git.exe"`.

## Review Focus

- **Utilisateur sans XP (nouveau compte)** : niveau 1, jardin avec une seule graine, pas d'erreur.
- **XP négatif ou null** : traité comme 0, pas de plantes débloquées.
- **Niveau max atteint** : barre à 100 %, pas d'erreur.
- **Actions qui échouent (409, 404)** : pas d'XP attribué.
- **Migration sur Neon** : colonne `xp` avec défaut 0, pas de perte de données.

### Task 1: Logique pure du jardin

**Files:**
- Create: `src/lib/jardin.ts`
- Test: `tests/jardin.test.ts`

**Interfaces:**
- Produces:
  - `type ActionXp = "repas_planifie" | "course_cochee" | "recette_ajoutee" | "recette_validee" | "semaine_complete"`
  - `NIVEAUX: { niveau: number; xpRequis: number; plante: string; emoji: string }[]`
  - `calculerNiveau(xp: number): { niveau: number; xpActuel: number; xpPourSuivant: number; progression: number }`
  - `plantesDebloquees(xp: number): { emoji: string; nom: string; niveau: number }[]`
  - `xpPourAction(action: ActionXp): number`

- [ ] **Step 1: Write the failing tests**

```ts
import { describe, it, expect } from "vitest";
import { calculerNiveau, plantesDebloquees, xpPourAction, NIVEAUX } from "@/lib/jardin";

describe("calculerNiveau", () => {
  it("niveau 1 pour 0 XP", () => {
    const r = calculerNiveau(0);
    expect(r.niveau).toBe(1);
    expect(r.xpActuel).toBe(0);
    expect(r.progression).toBe(0);
  });
  it("niveau 2 à 50 XP", () => {
    const r = calculerNiveau(50);
    expect(r.niveau).toBe(2);
    expect(r.xpPourSuivant).toBe(150);
  });
  it("niveau max pour XP très élevé", () => {
    const r = calculerNiveau(99999);
    expect(r.niveau).toBe(NIVEAUX.length);
    expect(r.progression).toBe(100);
  });
  it("gère un XP négatif comme 0", () => {
    expect(calculerNiveau(-10).niveau).toBe(1);
  });
});

describe("plantesDebloquees", () => {
  it("débloque la graine au niveau 1", () => {
    const plantes = plantesDebloquees(0);
    expect(plantes.length).toBeGreaterThanOrEqual(1);
    expect(plantes[0].emoji).toBe("🌱");
  });
  it("débloque plus de plantes avec plus d'XP", () => {
    const bas = plantesDebloquees(0);
    const haut = plantesDebloquees(500);
    expect(haut.length).toBeGreaterThan(bas.length);
  });
});

describe("xpPourAction", () => {
  it("retourne les bonnes valeurs", () => {
    expect(xpPourAction("repas_planifie")).toBe(5);
    expect(xpPourAction("course_cochee")).toBe(2);
    expect(xpPourAction("recette_ajoutee")).toBe(10);
    expect(xpPourAction("recette_validee")).toBe(15);
    expect(xpPourAction("semaine_complete")).toBe(50);
  });
});
```

- [ ] **Step 2: Run test to verify it fails** — `npx vitest run tests/jardin.test.ts` → FAIL.

- [ ] **Step 3: Implement `src/lib/jardin.ts`**

`NIVEAUX` : tableau de 10 niveaux avec xpRequis, plante, emoji.

`calculerNiveau(xp)` : xp = Math.max(0, xp || 0). Trouver le niveau le plus élevé où xp >= xpRequis. xpActuel = xp - xpRequis du niveau actuel. xpPourSuivant = xpRequis du niveau suivant (ou xpActuel si max). progression = (xpActuel / (xpPourSuivant - xpRequisNiveauActuel)) * 100, borné 0-100.

`plantesDebloquees(xp)` : retourner toutes les plantes dont le niveau requis ≤ niveau actuel.

`xpPourAction(action)` : switch sur l'action, retourner la valeur correspondante.

- [ ] **Step 4: Run test to verify it passes** — `npx vitest run tests/jardin.test.ts` → PASS.

- [ ] **Step 5: Commit** — `git add src/lib/jardin.ts tests/jardin.test.ts; git commit -m "feat: add pure garden XP logic"`.
