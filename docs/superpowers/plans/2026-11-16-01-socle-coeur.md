# Plan 1/5 — Socle & cœur repas — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fondations de Miamz : app Next.js déployée sur Vercel avec auth Google, accès par clés d'activation admin, et la boucle cœur — recettes → calendrier de la semaine → liste de courses auto-triée.

**Architecture:** Next.js 15 App Router full-stack (UI + route handlers), Prisma/Neon PostgreSQL, Auth.js v5 (Google), logique métier extraite en fonctions pures testées (licences, agrégation courses, semaines, rayons). La mascotte Miamz n'existe ici que comme statuette SVG statique dans le header — son moteur arrive au plan 2.

**Tech Stack:** Next.js 15, TypeScript, Tailwind CSS v4, shadcn/ui, Prisma + Neon PostgreSQL, Auth.js v5 (`next-auth@beta` + `@auth/prisma-adapter`), Zod, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-16-miamz-design.md` (plans 2 à 5 couvriront : Miamz/IA, gamification/foyer, stock/DLC/barcode, PWA/push/rapports).

## Global Constraints

- 100 % gratuit : Vercel Hobby, Neon Free, aucun service payant. Aucune clé d'API IA dans ce plan.
- OpenRouter jamais côté navigateur (n'entre en jeu qu'au plan 2).
- Interface 100 % en français (libellés, boutons, erreurs, emails).
- Identité : palette pastel — rose `#FFB5C2`, menthe `#A8E6CF`, crème `#FFF9E6`, lavande `#C9B6E4`, vert sauge `#4A6741`, terracotta `#E07A5F` ; police ronde **Fredoka** (Google Fonts) ; coins arrondis, ambiances douces.
- Auth : Google OAuth uniquement, pas de magic links.
- Rôle `ADMIN` = premier compte enregistré ; les autres comptes doivent activer une clé (existe en base, statut ni `REVOKED` ni expirée).
- Codes de clés : format `MIAMZ-XXXX-XXXX-XXXX` (alphabet Crockford `23456789ABCDEFGHJKMNPQRSTVWXYZ`, pas de 0/1/O/I/L).
- Semaine ISO : lundi = premier jour.
- Node 22. Tous les tests passent avec `npm test` (Vitest) avant chaque commit.
- Identifiants de code en anglais, chaînes affichées en français.

## Review Focus

1. **Clé expirée à l'instant de la requête** : une clé dont `expiresAt <= now` doit être traitée comme expirée (pas « active ») — testé Task 3 (`licenseStatus` à la frontière).
2. **Session valide mais sans clé active** : l'utilisateur authentifié sans clé doit être renvoyé vers `/connexion?erreur=cle`, jamais dans l'app — testé Task 4 (`routeGuard`).
3. **Doublons d'ingrédients à unités différentes** (« 500 g » + « 0,5 kg ») : v1 fusionne uniquement même nom + même unité, sinon lignes séparées — testé Task 8 (`aggregateGroceries`).
4. **Servings non divisibles** (base 2 → cible 3 donne ×1,5) : quantités gardées à 2 décimales, affichées à la française (« 2,25 ») — testé Task 8 (`scaleQuantity`, `formatQuantite`).
5. **Semaine à cheval sur deux mois / année** : `getWeekDates` doit renvoyer les 7 jours corrects depuis n'importe quel jour — testé Task 7.
