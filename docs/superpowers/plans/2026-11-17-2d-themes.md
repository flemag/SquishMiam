# Plan 2d « Miamz en couleurs » — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un système de thèmes complet (3 thèmes au choix, « Manga food truck » par défaut), fond animé par thème, habillage sémantique de toute l'app, Miamz contextuel au tap sur chaque page, sélecteur de thème dans la barre du haut.

**Architecture:** Un thème = un jeu de variables CSS (palette + géométrie) posé sur `<html data-theme="…">` par le layout racine (cookie `miamz-theme`). Toute l'habillage passe par un petit jeu de classes sémantiques (`.carte`, `.bouton`…) et des utilitaires tokens Tailwind. Le fond animé est un composant serveur unique piloté par le `data-theme` (CSS only, transform/opacity).

**Tech Stack:** Next.js 15 App Router, TypeScript, Tailwind 4 (`@theme inline` + `@layer components`), Vitest, SVG inline (zéro dépendance).

**Spec:** `docs/superpowers/specs/2026-11-17-themes-design.md` (approuvé, palettes extraites des maquettes + résolutions du builder-check)

## Global Constraints

- Animations `transform`/`opacity` uniquement ; `prefers-reduced-motion` → tout s'arrête (fond compris), l'information reste lisible.
- Mobile + desktop : 360 px, cibles tactiles ≥ 44 px, **aucun débordement de page**.
- UI 100 % française ; Fredoka ; **zéro nouvelle dépendance npm** ; SVG inline type Lucide.
- TDD sur la logique pure (Vitest) ; `npm test` + `npm run build` verts avant chaque commit.
- Les bulles d'humeur spontanées du compagnon restent **inchangées** ; le tap n'émet **aucun** événement moteur d'humeur.
- Palette contractuelle (`--miamz-rose/menthe/lilas/vert/corail`) constante entre thèmes ; l'identité vient du fond, des traits, ombres, rayons, boutons (valeurs exactes : tableau de la spec).

## Review Focus

1. **Cookie absent/corrompu** (`miamz-theme: "sombre"`, vide, undefined) → thème `manga` rendu, jamais de page sans thème — test dans Task 1 (`themeDepuisValeur`).
2. **Chemins imbriqués et inconnus** dans `bullesPourChemin` (`/recettes/nouvelle` → pool recettes, `/admin/cles` → pool générique, jamais vide) — tests dans Task 1.
3. **`prefers-reduced-motion`** : damier ET doodles immobiles, fond et bulles toujours lisibles — sélecteurs ajoutés au bloc `@media` dans Task 2.
4. **Fond masqué par un wrapper opaque** : tout `bg-[#FFF9E6]` opaque sur un conteneur de contenu doit disparaître (le fond fixe serait invisible sinon) — étape de vérification dédiée dans Task 2 (grep + build).
5. **Tap sur Miamz** : aucun appel `emettre`/moteur d'humeur ; les bulles spontanées (événement frais) ne sont pas perturbées — inspection + suite verte dans Task 4.

- [ ] **Step 1: Write the failing test** — `tests/themes.test.ts`

```ts
import { describe, it, expect } from "vitest";
import { bullesPourChemin, themeDepuisValeur, THEMES, THEME_DEFAUT } from "@/lib/themes";

describe("themeDepuisValeur", () => {
  it("accepte les 3 ids valides", () => {
    expect(themeDepuisValeur("manga")).toBe("manga");
    expect(themeDepuisValeur("doux")).toBe("doux");
    expect(themeDepuisValeur("pique-nique")).toBe("pique-nique");
  });
  it("retombe sur manga si absent ou invalide", () => {
    expect(themeDepuisValeur(undefined)).toBe("manga");
    expect(themeDepuisValeur(null)).toBe("manga");
    expect(themeDepuisValeur("")).toBe("manga");
    expect(themeDepuisValeur("SOMBRE")).toBe("manga");
    expect(themeDepuisValeur("manga; path=/evil")).toBe("manga");
  });
});

describe("THEMES", () => {
  it("propose 3 thèmes avec labels et aperçu", () => {
    expect(THEMES).toHaveLength(3);
    expect(THEMES.map((t) => t.id)).toContain(THEME_DEFAUT);
    for (const t of THEMES) {
      expect(t.label.length).toBeGreaterThan(0);
      expect(t.apercu.fond).toMatch(/^#/);
      expect(t.apercu.accent).toMatch(/^#/);
    }
  });
});

describe("bullesPourChemin", () => {
  it("donne un pool propre à chaque page", () => {
    const plan = bullesPourChemin("/plan");
    const recettes = bullesPourChemin("/recettes");
    const courses = bullesPourChemin("/courses");
    expect(plan.length).toBeGreaterThanOrEqual(3);
    expect(recettes).toEqual(bullesPourChemin("/recettes/nouvelle")); // préfixe
    expect(plan).not.toEqual(recettes);
    expect(courses).not.toEqual(plan);
  });
  it("donne le pool générique partout ailleurs, jamais vide", () => {
    const defaut = bullesPourChemin("/admin/cles");
    expect(defaut.length).toBeGreaterThanOrEqual(3);
    expect(bullesPourChemin("/")).toEqual(defaut);
  });
});
```
